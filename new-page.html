📄 Новая страница

Создаёт страницу-заготовку имя.md и (по желанию) добавляет её карточку в список раздела (coils.md / wands.md / other.md). Делает то же, что скрипт .github/scripts/new_page.py, но без запуска workflow.

Страница

Имя: только латиница, цифры, - и _ (без пробелов и русских букв), до 61 символа. Если в имени есть coil — тип катушка, wand — палочка.

Предпросмотр .md

Текст можно поправить прямо здесь — зальётся именно он. Если поменять имя, тип или название, предпросмотр пересоберётся заново.

Залить в GitHub

Нужен fine-grained токен только для этого репозитория с правом Contents: Read and write. Токен хранится только в поле на странице и пропадает при обновлении.
