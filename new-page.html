📄 Редактор страниц

Создаёт новую страницу или правит существующую в docs/, добавляет карточку в список раздела и рисует обложку, всё одним коммитом. Без Markdown: «Простой» режим для текста по полям.

🔑 Подключение к GitHub

Токен fine-grained, только для этого репозитория, право Contents: Read and write. Если запомнить, он лежит в localStorage этого браузера (виден любому скрипту на этом сайте), поэтому включай только на своём устройстве. Без токена можно писать и скачать .md: заливать будет тот, у кого токен.
